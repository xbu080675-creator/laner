# Laner

Laner 是电竞观赛助手的下一代重构工程。

## 核心原则

- **功能不改，底层重做。**
- **可以快，但不能以跳过质量门禁换速度。**
- **聊天不是工程记忆，仓库才是。**
- **每一次开发都必须留档。**

当前只建立工程治理、范围和目标架构，尚未开始业务代码迁移，也没有任何运行环境被声明为正式支持。
