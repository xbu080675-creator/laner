# Laner Project Scope

## 项目定位

Laner 是现有电竞观赛助手的下一代重构工程。

本轮重构的产品原则只有两句：

> **功能不改。**
>
> **底层重做。**

旧版本承担行为基线与功能参考，新仓库承担新的长期可维护实现。

## 一级产品结构

Laner 的所有用户可见业务页面、主路由、赛事信息与观赛能力，必须首先以比赛生命周期划分为：

1. `PRE_MATCH` / 赛前
2. `LIVE_MATCH` / 赛中
3. `POST_MATCH` / 赛后

该三阶段不是首页装饰或三个普通 Tab，而是一级产品与架构分类轴。

赛程、首发、Rank、积分、HUD、沙盘、赛后数据、复盘等属于具体功能，它们必须挂靠到对应阶段；共享的设置、搜索、数据源、缓存、AI/OCR、日志诊断等基础能力可以跨阶段复用，但不能形成第四个业务阶段。

## 全球赛事统一管理

Laner 不再按照“一个赛区一套业务系统”的方式开发。

正式原则：

> **全局管理，全局接管；赛区是数据维度，不是架构边界。**

因此：

- LPL、LCK、LEC、LCS 及后续其他联赛/国际赛事共享同一 Competition / Team / Player / Match / Game / Standing / Qualification 领域模型；
- 赛区专属差异只能通过 Provider Adapter、Ruleset、Capability、赛事元数据或配置表达；
- 禁止复制一套 `LPL` 业务逻辑后再复制 `LCK` / `LEC` 版本；
- 页面允许按赛区、赛事、赛季筛选，但页面本身不属于某个赛区；
- 国际赛事、跨赛区转会、队伍更名、赛制调整必须能够在统一领域模型中表达；
- 全局架构并不自动等于“全球全部赛区当前已验证支持”，真实支持范围必须继续由数据源能力和测试证据决定。

详细架构以 `docs/ARCHITECTURE.md` 为准。

## 体验北极星：极简 + 酷炫

Laner 的视觉与交互统一以：

> **极简**
>
> **酷炫**

为体验北极星。

但优先级固定为：

```text
清晰 / 快速 / 不打扰观赛
>
电竞感 / 动效 / 视觉冲击
```

因此：

- 极简不等于功能少，而是当前阶段只给用户此刻真正有价值的信息；
- 酷炫必须服务状态变化、赛事临场感和信息理解；
- 任何动效、光效、动画、HUD 如果降低可读性、遮挡比赛、延迟信息、增加操作成本，必须删减；
- 赛前视觉节奏应安静、清楚；赛中允许最强电竞临场感；赛后主动降低动态强度，转向解释和复盘；
- 详细规范以 `docs/UX_PRINCIPLES.md` 为准。

## 本轮允许改变的内容

- 模块边界与目录结构；
- Core / Application / Port / Adapter 架构；
- 数据标准化与数据源接入方式；
- 赛事状态机 / Event Engine；
- 全球赛事、赛区、赛事、队伍、选手的统一身份与领域建模；
- 网络层、缓存、数据库和持久化；
- 后台任务与轮询调度；
- OCR / AI / 外部源接入方式；
- 日志、错误码、诊断、测试、构建和 CI；
- 内部接口，只要不无故改变外部可见行为。

## 本轮默认禁止改变的内容

在形成 `FEATURE_BASELINE.md` 并逐项迁移前，默认禁止因“重构方便”而删除、缩水或静默改变：

- 现有用户可见功能；
- **赛前 / 赛中 / 赛后三阶段一级产品结构；**
- **全球统一赛事管理，不按赛区复制业务系统；**
- **极简 + 酷炫的体验北极星；**
- 已存在的核心数据展示能力；
- 已确定的赛事辅助定位与交互逻辑；
- 现有关键 UI 行为和用户操作习惯；
- 已验证的数据能力。

如某项确实必须变化，必须单独立项、记录原因、兼容影响和验收方式。

## 三阶段页面规则

- 每个用户可见业务页面必须有明确 Phase。
- 一级业务导航不得用“赛程 / 数据 / 分析 / 直播”等功能类别取代三阶段。
- 比赛阶段由统一 Match State 决定，页面不得自行推断。
- “赛事直播开始”与“游戏进入”必须区分；选手入场、评论席、BP、载入、局内、局间均属于赛中内部细状态。
- 同一领域能力跨阶段复用时必须共享 Domain/Application 能力，不允许复制三套业务规则。
- 无法归属三阶段的新增业务页面必须先进行架构评审。
- 赛区只能作为筛选、上下文和赛事属性，不能成为独立一级业务页面或独立产品架构。

## 旧工程使用方式

旧工程只作为：

1. 功能清单来源；
2. 行为基准；
3. UI/交互参考；
4. 数据格式与历史问题参考；
5. 回归对照。

旧代码不得未经审查直接复制到 Laner。
