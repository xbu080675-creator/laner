## M1 — Core Migration

任务在旧工程功能基线提取后拆分。不得在不知道完整功能基线前为了“快”提前编造迁移顺序。

## 速度原则

允许：
- 并行读取与分析；
- 一次完成同一责任域内的一组改动；
- 使用自动化测试、生成和检查减少人工重复；
- 在需求已确定时直接实现，不重复讨论已确认需求。

禁止：
- 为赶进度跨模块乱改；
- 跳过测试；
- 跳过留档；
- 先写临时代码以后再重构；
- 把未执行测试写成 PASS；
- 在功能基线未知时删除旧能力。
